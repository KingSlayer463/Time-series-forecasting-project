# Time Series Forecasting Projects

This repository contains a collection of time series forecasting projects developed in Python. The projects focus on applying statistical forecasting methods to real-world datasets, evaluating model performance, and selecting appropriate models based on out-of-sample forecasting accuracy.

## Projects

### 1. Stock Price Forecasting

This project explores time series forecasting techniques for predicting stock prices.

Key topics include:

- Time series visualization
- Exploratory data analysis
- ETS models
- Train/test splitting
- Forecast evaluation
- Model comparison and selection

Evaluation metrics include:

- RMSE
- MAE
- MAPE
- Additional forecast accuracy metrics

📁 [View Stock Price Forecasting Project](./stock-price-forecasting)

---

### 2. Australian Pharmaceutical Sales Forecasting

This project analyzes monthly Australian anti-diabetic drug sales and applies ARIMA-based forecasting techniques.

Key topics include:

- Time series visualization
- Stationarity
- Differencing
- Autocorrelation Function (ACF)
- Partial Autocorrelation Function (PACF)
- AR and MA processes
- ARIMA model development
- Backtesting
- Forecast evaluation
- Model selection

📁 [View Australian Drug Sales Forecasting Project](./australian-drug-sales-arima)
