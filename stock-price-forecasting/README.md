# Stock Price Forecasting

This project applies time series forecasting methods to predict stock prices and compare different forecasting models.

## Methods
- Time series visualization
- ETS models
- Train/test split
- Forecast evaluation
- RMSE
- MAE
- MAPE
- Additional accuracy metrics

## Tools
- Python
- pandas
- NumPy
- matplotlib
- statsmodels

## Goal
The goal of this project is to compare multiple forecasting approaches and identify the model that provides the best predictive performance.
