# Australian Drug Sales Forecasting with ARIMA

This project applies time series forecasting techniques to monthly Australian anti-diabetic drug sales.

The analysis focuses on evaluating multiple ARIMA and ETS models using rolling backtesting and selecting a model based on out-of-sample forecasting performance.

## Methods

- Time series visualization
- Stationarity analysis
- Differencing
- Autocorrelation Function (ACF)
- Partial Autocorrelation Function (PACF)
- AR and MA process identification
- ARIMA modeling
- ETS modeling
- Rolling backtesting
- Forecast evaluation
- Model comparison and selection

## Backtesting

Twelve-month forecasts were evaluated across four test periods:

- July 2004 – June 2005
- July 2005 – June 2006
- July 2006 – June 2007
- July 2007 – June 2008

## Tools

- Python
- pandas
- NumPy
- matplotlib
- statsmodels
- Jupyter Notebook

## Goal

The goal of this project is to compare forecasting models across multiple historical test periods and select an appropriate model for predicting the next 12 months of Australian anti-diabetic drug sales.
